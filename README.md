# Portfólio Gabrieli

Fundação do portfólio em React, TypeScript e Vite. A interface está intencionalmente mínima para servir de base às próximas etapas.

## Requisitos

- Node.js 20.19+ ou 22.12+
- npm

## Executar

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev`: inicia o servidor local.
- `npm run build`: verifica os tipos e gera a versão de produção em `dist/`.
- `npm run lint`: analisa os arquivos TypeScript e React com ESLint.

## Organização

- `src/app`: composição principal da aplicação.
- `src/components`: componentes reutilizáveis.
- `src/sections`: seções da página.
- `src/data`: conteúdo separado da interface.
- `src/styles`: tokens, temas e estilos globais.
- `public`: arquivos estáticos.
